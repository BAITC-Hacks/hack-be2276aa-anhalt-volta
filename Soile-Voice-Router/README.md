# Voice Router • Saqta Insurance

Прототип маршрутизатора клиентских обращений для хакатона: чат на русском и казахском, голосовой ввод и панель супервизора. Не является продуктом банка и не выполняет банковских операций.

## Возможности

- Две колонки: чат клиента и панель результатов.
- Подключён локальный роутер из `../router/router.py` с 40 страховыми сценариями.
- Демо без ключа и сети: маршрутизация на русском, казахском и смешанной речи.
- Панель супервизора показывает сценарий, уверенность, обоснование, альтернативы и дополнительные задачи.
- Озвучка ответа выполняется голосом браузера/ОС; STT пока подключается отдельным модулем.
- Реальные замеры STT и маршрутизации, просмотр и скачивание JSON.

## Быстрый запуск

Нужен Python 3.11+. Из корня проекта:

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Активация в macOS/Linux:

```bash
source .venv/bin/activate
```

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте http://localhost:8501. По умолчанию включён деморежим, ключ не нужен.
Если установлен `uv`, можно вместо этих команд выполнить `uv venv --python 3.11`, `uv pip install -r requirements.txt`, затем `uv run --no-project streamlit run app.py`.

## Подключение OpenAI

Скопируйте `.env.example` в `.env` и укажите ключ:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-5-mini
```

Установите зависимость `openai` и перезапустите Streamlit. В интерфейсе выберите «OpenAI онлайн». Если API недоступен или модель вернула неизвестный сценарий, используется локальный роутер как fallback.

Имя модели по умолчанию сохранено из исходного проекта: `gemini-3.6-flash`. Доступность зависит от аккаунта; при ошибке модели измените `GEMINI_MODEL`. Ключ создаётся в [Google AI Studio](https://aistudio.google.com/apikey). Расходы и квоты относятся к Gemini API, а не к подписке ChatGPT.

Запись распознаётся только после нажатия «Распознать и отправить». Используйте короткие записи до 5 МБ. Микрофон требует разрешения браузера и localhost или HTTPS. Для озвучки нужен голос соответствующего языка в браузере/ОС; казахский голос доступен не везде. Смешанный текст озвучивается русским голосом.

## Как устроено

```text
Текст ───────────────────────────┐
Микрофон → WAV → Gemini STT ─────┤
                                ↓
                    Insurance Router + история диалога
                                ↓
                     Проверенный JSON (Pydantic)
                                ↓
                 Чат + панель супервизора + TTS
```

`app.py` — интерфейс; `agent.py` — адаптер к `../router/router.py`; `config.py` — настройки. `main.py` оставляет консольный режим: `python main.py`.

Контракт `route(text, history, mode)` возвращает `scenario_id`, `confidence`, `explanation`, `alternatives`, `reply`, `language`, `mode`, `model`, `routing_ms`. UI добавляет `input`, `stt_ms`, `processing_ms`, `tts_ms`. `confidence=null` в демо; `tts_ms=null`, поскольку браузерная задержка отображается отдельно и не включается в серверные замеры.

## Демонстрация

В разделе «Попробовать демо-диалог» выберите пример и отправляйте реплики кнопкой. Есть русский, казахский, смешанный запрос и смена темы. Демо — ограниченная проверка интерфейса, не оценка качества LLM; оно не учитывает прошлые сообщения. Для проверки контекста и свободной речи переключитесь в онлайн-режим.

Самооценка уверенности модели не является точностью. Время «Всего до ответа» исключает запись и воспроизведение. Задержка менее 500 мс не гарантируется. Результаты распознавания и классификации требуют проверки на отдельном наборе диалогов.

## Тесты

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты не обращаются к API: проверяют маршруты демо, неоднозначность, смену намерения, валидацию ответа, передачу истории и работу UI. GitHub Actions запускает их при push и pull request.

## Публикация в GitHub

`.env`, виртуальное окружение, кэши и `.streamlit/secrets.toml` исключены из Git. `.env.example` содержит только пустой ключ. Перед первым коммитом проверьте `git status --short`; публикуйте исходники, README, конфигурацию и тесты. Этот проект не содержит авторизации или ограничений запросов для публичного сервера: запускайте локально для демо, прежде чем добавлять публичный доступ к платному API.

Сообщения и трассировки хранятся в сессии (последние 20 обращений); сбрасываются кнопкой очистки или при смене режима. Скачанный JSON содержит текст обращений. В онлайн-режиме текст, контекст и отправленная запись передаются Google. Не используйте реальные банковские реквизиты и персональные данные в демо.
